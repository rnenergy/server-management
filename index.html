Plan parameters

Included hours are engineer time for any task in the table below. They are spent on tasks you request in a ticket or approve after a monitoring alert. Monitoring itself does not use hours. Work beyond the included hours, including tasks from a higher plan, is €30/hour and is estimated and agreed before it starts.

What each plan covers

Per server. Guest operating systems on your hypervisor need a separate plan per VM.

Per node. Guest operating systems need a separate plan per VM.

Per server. Hyper-V guest operating systems need a separate plan per VM.

Reboot, rescue mode, standard OS reinstall, hardware replacement and root or Administrator password reset are standard support, included with every server, and do not use plan hours.
