Server management

Работы выполняются по запросу через тикет в рамках включённых часов. Без запроса – только мониторинг: при срабатывании триггера клиент получает уведомление, дальнейшие действия согласуются. При критических уязвимостях и вышедших обновлениях ОС, панелей управления и установленного ПО клиент получает уведомление с предложением устранить уязвимость или обновиться в рамках тарифа.

Мониторинг сервера и мониторинг безопасности работают постоянно и в часы не входят.
